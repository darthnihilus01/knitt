# Knitt 0.1.0-beta.2

Local conversation memory preview. npm package: `@tinchu0/knitt`; distribution tags: `latest` and `next`.

## Changes

- Opt-in capture for fresh coding sessions, without selecting an existing chat first.
- Independent destination histories with explicit source links and frozen evidence, checkpoint and provenance snapshots.
- Stored-chat selection and supported local Codex, Claude Code and Antigravity history discovery.
- Cited, versioned checkpoints with reported verification status, explicit retirement and bounded checkpoint-first recall.
- Startup-issued session capabilities for conversation-mode tools, durable per-event delivery identities and per-session capture diagnostics.
- Additive SQLite migrations, consistent backups and incompatible-runtime rollback checks.

## Install or update

```bash
npx @tinchu0/knitt@latest setup --workspace /path/to/project --client codex --capture-new-sessions
npx @tinchu0/knitt@latest update --yes
```

Updating retains existing capture preferences. Run setup with `--capture-new-sessions` to enable the new mode deliberately. Restart connected agents and approve their normal MCP/hook trust prompts. Existing project installations and memory are not modified by publishing this release.

## Validation and limits

Release checks include TypeScript validation, 77 tests, real tarball installation, generated startup/capture hooks, capability-protected checkpoint handoff, source-history isolation, doctor, update/rollback, failure preservation and uninstall. Release publication additionally uses an npm dry run and scoped credential scans.

The new conversation mode is local-only and requires Node.js 24+. Desktop and remote ordinary-chat connections retain their legacy behavior. Native all-client lifecycle coverage remains incomplete; Claude Code was unauthenticated for a live pilot. The earlier synthetic live Codex recall pilot preceded final capability enforcement; the final external-model recheck remains unapproved. Very-long-history query optimization is deferred. See [local memory setup and recovery](../clients/local-agent-memory.md).
