# Knitt beta.12 — Live conversation sharing

Owned synced conversations now have Share conversation: review the current history and whole-chat/future-message scope, choose an accepted friend, and confirm. The recipient accepts a live invitation and can read the conversation in Shared with me or explicitly load it through /knit.

Live access is read-only and separate from published context snapshots. It exposes one conversation, never its entire project. Friendship removal atomically withdraws pending invitations and revokes live grants in both directions. Reconnecting or re-inviting never restores a prior grant. All history, search and evidence reads check current access. Previously loaded text may remain in chats or local storage.

The browser checks for updates every30s while visible, preserves loaded messages offline, and clears its view on confirmed access loss. Agent continuations pin a cutoff until explicitly reselected; recipient work remains separate.
