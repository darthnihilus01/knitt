# Knitt 0.1.0-beta.3

Native platform setup preview. npm package: `@tinchu0/knitt`; distribution tags: `latest` and `next`.

## Changes

- Native Windows installation, with PowerShell startup/capture hooks and shell-free npm execution.
- Preserve existing POSIX hooks and macOS Application Support storage.
- Portable runtime and package smoke checks, with Windows added to the Linux/macOS CI matrix.
- Quoted Windows/macOS setup examples and prerequisites.
- Preserve beta.2 local conversation capture, session capabilities, checkpoint handoffs, memory migrations and runtime downgrade safeguards.

## Install or update

```sh
npx @tinchu0/knitt@latest setup
npx @tinchu0/knitt@latest update --yes
```

Node.js 24+ with npm and Git are required. Windows hooks use built-in Windows PowerShell 5.1. Restart connected agents and approve their normal MCP/hook trust prompts. Existing installations retain memory and capture preferences.

## Verification

Release validation includes type checking, the full suite, a real tarball lifecycle smoke test, and npm publish dry run. The CI matrix runs the suite and packaged hook/capture/checkpoint handoffs on Linux, macOS and Windows. These checks do not establish every application's live handoff behavior.
