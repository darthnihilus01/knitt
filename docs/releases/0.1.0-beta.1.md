# Knitt 0.1.0-beta.1

Prepared for the public npm `next` tag; publication is pending.

- Package: @tinchu0/knitt
- License: Apache-2.0
- CLI: knitt
- Requires Node.js 24+ and Git. No Python requirement on npm installation paths.
- Local Linux package installation and lifecycle verified. macOS live behavior remains unverified. Native Windows setup is blocked; WSL uses the Linux path.
- Claude Desktop still requires merging its generated configuration fragment.
- Local installation does not synchronize teammate machines. ChatGPT/Claude web require a separately deployed HTTPS/OAuth gateway.
- Current conversation discovery imports local Antigravity history; it does not browse all agents' cloud chat histories.

Validation: TypeScript checking, 48 regression tests, clean npm tarball installation, bootstrap removal, MCP/recall hook execution, doctor, update, rollback, failed-install preservation and uninstall pass. npm publish dry run passes with public access and tag next. A dry run does not prove registry publication authorization.

Intended post-publication command:

```bash
npx @tinchu0/knitt@next setup
```
